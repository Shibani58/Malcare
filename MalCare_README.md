1. Download the MalCare folder.
2. Download Anaconda Spyder IDE.
3. In that IDE console install the following packages in the same order:-
     pip install flask
     pip install flask_socketio
     pip install numpy
     pip install tensorflow
     pip install matplotlib
     pip install pyrebase
     pip install nltk
4. Open the MalCare folder directory in Spyder.
5. Double click on the "app.py" file and open it.
6. Click on Run.
7. The project will start running and it will be reflected in the console.
8. When the project has successfully run, the console will provide a localhost address, for exampe:-  http://127.0.0.1:5000/
9. Copy that link and paste it in the browser to enter the front page of the MalCare website.
